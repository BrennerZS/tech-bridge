# TECH BRIDGE

Crie uma plataforma web completa, profissional e original para uma startup/agência de tecnologia que desenvolve sites, aplicativos, sistemas e soluções digitais para pessoas, empresas e empreendedores, combinada com uma comunidade ativa de desenvolvedores.

Direção visual e sonora baseada no Install antislop | Agent Installation & Setup (https://antislop.ai.id/ e https://antislop.ai.id/install):
- Princípios Anti-Slop: zero layouts genéricos de IA, sem gradientes roxo/azul clichês, sem cards repetitivos ou dados inventados. Estética técnica de alto contraste, tipografia editorial e mono expressiva, microinterações precisas, abas estilo hub/pills táteis e terminal/código limpo.
- Sistema de áudio interativo sintetizado com Web Audio API (e fallback de áudio): sons táteis de navegação (nav tick), confirmação (enter chime), retorno (back), alternância de abas (hub/badge tab) e cópia (copy click).
- Controle global de som (toggle Muted / Sound ON) nos controles do sistema, respeitando acessibilidade.
- Segurança máxima e arquitetura robusta no backend (Supabase com autenticação, PostgreSQL, Storage, Realtime e Row Level Security rígido para que nenhum usuário altere ou exclua dados de outro).

Estrutura e funcionalidades completas conforme especificado:
1. Home com apresentação marcante da agência, serviços, metodologia, projetos e chamadas para clientes e comunidade.
2. Sobre Nós e Serviços detalhados com formulário funcional de orçamento.
3. Portfólio com filtros por categoria e tecnologias.
4. Comunidade de Desenvolvedores com perfis públicos personalizáveis (bio, skills, links, projetos, disponibilidade).
5. Feed da Comunidade com publicações, upload de imagens, curtidas, comentários e filtros.
6. Central de Conversas com 3 salas em tempo real: Chat Geral, Chat de Ideias e Chat de Ação.
7. Projetos Colaborativos e Mural de Oportunidades/Vagas.
8. Autenticação completa e Dashboard do Usuário.
9. Painel Administrativo com proteção real de permissões.

Construa uma aplicação fluida, responsiva e 100% funcional.
